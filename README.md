# 🚀 Python Telepresence Cluster

## 📌 DESCRIPTION

Ce projet permet de développer une application Python 🐍 en local tout en l’exécutant dans un cluster Kubernetes ☸️ grâce à Telepresence 🔌.

Il facilite le développement hybride local + cloud ☁️ en redirigeant le trafic du cluster vers la machine locale sans rebuild ni redeploy constant.

---

## 🧱 STACK TECHNIQUE

- 🐍 Python
- 🐳 Docker
- ☸️ Kubernetes
- 🔌 Telepresence
- 🌐 Nginx

---

## ⚙️ PREREQUIS

Avant de commencer, installer :

- 🐳 Docker
- ☸️ Kubernetes (kubectl configuré)
- 🔌 Telepresence
- 🐍 Python 3.8 ou plus
- ☁️ Un cluster Kubernetes fonctionnel
